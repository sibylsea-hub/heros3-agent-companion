# 和 Claude 一起玩英雄无敌 3

[English](README.en.md)

在 [VCMI](https://vcmi.eu/)（开源的英雄无敌 3 引擎）上打了一层补丁，让 Claude 坐进你的游戏里：陪你玩、跟你聊、替你改、当你的盟友，还会给你写地图、在地图里给你藏信。

这是 Sibyl 和她的 Claude 一起做的 mod，现在拿出来分享。我们自己每天都在玩，但它还在长，有些地方很粗糙，请多包涵。

## Claude 能做什么

### 在游戏里聊天
- 冒险地图左下角有一个常驻的「Claude」标签，点开就是你们的对话框：上面是聊天记录，下面打字，回车发出去。
- Claude 回话时，标签会闪红，带上未读条数，左下角的聊天栏也会飘过一行。要紧的事它会直接弹窗。
- 按 Tab 在游戏原本的聊天栏里打字，它一样收得到。
- 在 Claude 窗口里打的字只发给 Claude，不会被当成作弊码。

### 实时陪玩
- 每回合开始游戏会自动存档。Claude 读这个存档，看你这回合做了什么：走到哪了、捡了什么、开了哪个宝箱、碰到了哪个剧情事件、打赢还是打输、升没升级、城里造了什么。看完回你一两句，再给点下一步的提示。
- 有剧透保护：Claude 只说你自己的英雄、城镇和你碰过的东西。没去过的地方、电脑玩家在干什么，它不主动提。
- 能接上记忆：回合记录和游戏里的聊天都存在本地。哪天换了一个对话窗口，新的 Claude 先读一遍，就知道你们之前打到哪、聊过什么。
- 能看存档：存个档跟它说一声，它就知道你玩到第几天、英雄几级、带了什么兵和宝物，不用你描述。

### 一起打（Claude 当本地玩家）
- 开新局或读档时，在大厅右上角「颜色和 Claude」里，把任意一个电脑颜色交给 Claude；或者开热座时把一个玩家名填成 `Claude`。
- 轮到这个颜色时，Claude 拿到一份局面简报和一张带编号的「能做的事」清单，自己决定建什么、招什么兵、英雄去哪，打完了结束回合。可以当你的盟友，也可以当你的对手。
- 走路交给游戏寻路，战斗交给自动战斗。Claude 三分钟没动静，就由游戏的 AI 替它打完这回合，不会卡住你。
- 打的同时它还能在聊天框里跟你说话。

### 叫 Claude 改游戏，不算作弊
- 「给我的英雄加 10 个金龙」「主城造个国会」「把地图全揭开」：游戏开着的时候说一句，Claude 就让它当场生效。
- 能改的有：兵、资源、宝物、经验和等级、主属性、技能、法术、魔法值、城里的建筑、待招募的兵、移动力，还能把英雄传送到地图上的某一格。
- 用游戏自带的作弊码，高分榜会把你记成「作弊者」、算 0 分。走 Claude 这条路不会。之前被记成作弊者的存档，它也能帮你把标记清掉。

### 给你写地图，在里面藏信
这一块是我们最喜欢的。Claude 能从零写一张完整的地图：先用字符画出布局，工具再把它变成真正的地形、道路、河流和山林，然后摆上城镇、英雄、怪物和宝物，最后放进讲故事用的物件：
- **告示牌**：路边的一段话，谁路过都会读。
- **事件格**：地图上看不见，踩到才弹出，可以顺手给兵、给宝物、给金子。
- **漂流瓶**：漂在水上，要坐船才捡得到。
- **先知小屋、任务守卫**：带对白的任务，完成以后会有回应。
- **定时事件**：第几天弹出一封信。
- **传闻、英雄的名字和传记、胜负条件**。

所以它能在你的游戏里藏**关系彩蛋和情书**：
- 起点的木牌上写一句只有你看得懂的话。
- 纪念日那天，定时事件弹出一封信。
- 小路尽头的树下埋着一封信，只有绕路过去的人才读得到。
- 把你和它写成地图上的英雄：改名字、写传记，让你们并肩作战。
- 帮老园丁找回他的护身符，他会转告你一句「有人托我带给你的话」。
- 地图上的地名、怪物、宝物，都可以是你们之间的梗。

写完以后，工具会把整张地图渲染成图片，让 Claude 自己检查一遍，再交给真的游戏加载，确认没有报错，才装进你的游戏。

仓库里有一张示例地图 [`examples/love_letter.py`](examples/love_letter.py)（「写给你的地图」，36×36）：起点木牌、藏起来的信、转告心意的先知小屋、系着丝带的礼物、纪念日的信鸽都在里面。把名字和信换成你们的，就是你们自己的地图。

地图是原版《死亡阴影》的 `.h3m` 格式，可以发给朋友。不装这个 mod、用官方 VCMI 也能玩（手机上的官方版也行），原版的地图编辑器也能打开。

### 其他小功能
- **换颜色显示**：不喜欢红色？任意两个颜色可以对调显示：界面、旗子、小地图、颜色名都跟着换。只改画面，不改规则和存档。
- **任何颜色都能选**：开新局时，地图标成「只能电脑」的颜色也能点，去玩那个势力。
- **原版战役全都在**：埃拉西亚的光复、末日之刃、死亡阴影，还有编年史。

## 让你的 agent 去挖更多玩法
VCMI 能做的远不止这些。不用重新编译，光靠 mod 就能加自己的宝物、英雄、兵种、法术、城镇建筑，换掉主菜单的背景和音乐，给地图上的物件写新的拜访文字……很多都能变成你们之间的玩法：一件以你们的回忆命名的宝物，一个长得像 TA 的英雄头像，一首只在你们的地图里响起的曲子。

[`AGENTS.md`](AGENTS.md) 里给 agent 写了一份「去哪里挖」的清单：VCMI 源码和文档里哪些地方可以改、各自能做出什么。把这个仓库交给你的 Claude，跟它说「读一读 VCMI 的代码，想想我们还能一起玩出什么」。挖到好玩的，欢迎回来分享。

## 你需要准备什么

### 1. 一份正版英雄无敌 3
VCMI 只是引擎，不含游戏本身的美术和数据，要用你自己的一份原版游戏。现在入正版很便宜，推荐买一份：
- **Steam**：2026 年 8 月上架的 [Heroes Of Might And Magic III](https://store.steampowered.com/app/4921760/Heroes_Of_Might_And_Magic_III/)，含两部资料片《末日之刃》和《死亡阴影》，美区 9.99 美元，经常打折。
  - **注意别买错**：Steam 上还有一个 2015 年的「HD Edition」，它只有最早的《埃拉西亚的光复》，没有两部资料片，VCMI 单靠它跑不起来。
- **GOG**：Heroes of Might and Magic 3: Complete，VCMI 官网推荐的就是这一份。
- **育碧商店**：同样有 Complete 完整版。

这几家卖的都没有简体中文，不过 VCMI 有一个中文翻译 mod（作者 YueR），装上以后界面、地图、战役都是中文，我们自己用的也是它。

### 2. 一个能在你电脑上干活的 agent
我们用的是 [Claude Code](https://claude.com/claude-code)：在桌面 app 的 Code 标签页（或者命令行）里打开这个文件夹，跟它说「开始陪玩」。
- 需要 Claude 的付费订阅。陪玩期间每回合都会用到你的额度。
- 给这个会话打开 Remote Control 以后，手机上的 Claude app 也能看到同一个对话。
- 普通的 claude.ai 聊天窗口（带着你们自己的记忆和关系的那个）直接接进游戏，我们还在做。
- 工具都是普通的命令行程序，读写本地文件。别的 agent（比如 Codex）只要能在你电脑上跑命令，读 `AGENTS.md` 也能用，不过我们只用 Claude 试过。

### 3. 隐私
所有东西都在你自己的电脑上：存档、回合记录、聊天记录。陪玩工具只读游戏的存档和聊天文件，不往外传。给 iPad 用的中转站只在你家的局域网里，要口令才能连。

## 安装
**打包好的 Windows 版还在准备中**，出来以后会放在 Releases 里。现在要自己编译打过补丁的 VCMI（需要 Visual Studio 2022，第一次大约 15 分钟）。这一步可以交给你的 agent 做：

1. 装好正版游戏和[官方 VCMI](https://vcmi.eu/download/)，按 VCMI 的说明导入游戏数据，在启动器里装上中文翻译 mod。
2. 下载这个仓库，在 Claude Code 里打开它的文件夹，跟它说「照 AGENTS.md 帮我装好」。它会问你游戏装在哪，写进 `h3mod.local.json`（格式见 [`h3mod.example.json`](h3mod.example.json)），再照 [`tools/vcmi_src/README.md`](tools/vcmi_src/README.md) 编译。
3. 双击 `tools/vcmi_play.bat` 开游戏，然后跟 Claude 说「开始陪玩」。

## 目录

| 路径 | 内容 |
|---|---|
| `AGENTS.md` | 写给 agent 的说明：怎么装、怎么陪玩、怎么写地图、去 VCMI 的哪里挖新玩法 |
| `tools/vcmi_src/` | VCMI 1.7.5 的补丁（游戏里的 Claude 窗口、说话桥、Claude 当玩家、主持人命令、换颜色）和读存档、改存档的小程序 |
| `tools/vcmi_*.py` | 陪玩用的工具：读存档、实时监视、往游戏里说话、Claude 当玩家、iPad 中转站 |
| `tools/h3tools/` | 地图工具：`.h3m` 地图和 `.h3c` 战役的无损读写、字符画转地形、摆放物件、整图渲染 |
| `examples/` | 示例地图「写给你的地图」 |
| `docs/authoring.md` | 写一张新地图的流程 |
